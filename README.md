# Marek Sinagl — Portfolio

This repository is the source for my personal website: a portfolio and showcase of selected work.

I am a product engineer with a background in architecture. I build and operate software end to end, and I practice architecture as a way of turning ambiguous needs into buildable solutions.

## What’s in this site

- **Home** — who I am, selected work, how I work, and a compact career history
- **Projects** — Archa, Mingly, and other software
- **Employment** — fuller role notes and education
- **Contact** — how to reach me

The site is a small Nuxt and Vue application, published at [marekmez.github.io/ms-porfolio](https://marekmez.github.io/ms-porfolio/). This repo is the public source for that site, not a product to install or run.
